## Data Cleaning

### Checking for NULL Values and Removing Them

The first step in data cleaning is identifying any NULL values in the dataset and then removing them. This query checks for missing values in the key columns:

```sql
--finding null values
SELECT * FROM retail_sales
WHERE 
    sale_date IS NULL OR sale_time IS NULL OR customer_id IS NULL OR 
    gender IS NULL OR age IS NULL OR category IS NULL OR 
    quantity IS NULL OR price_per_unit IS NULL OR cogs IS NULL;
--deleting null values
DELETE FROM retail_sales
WHERE 
    sale_date IS NULL OR sale_time IS NULL OR customer_id IS NULL OR 
    gender IS NULL OR age IS NULL OR category IS NULL OR 
    quantity IS NULL OR price_per_unit IS NULL OR cogs IS NULL;
```
## Data Exploration
To get an overview of the dataset. 

```sql
--Total Number of Sales
SELECT COUNT(*) FROM retail_sales;
--Number of Unique Customers
SELECT COUNT(DISTINCT customer_id) FROM retail_sales;

--Types of Categories
SELECT DISTINCT category FROM retail_sales;

--Total Sale Value
SELECT SUM(total_sale) AS total_sales FROM retail_sales;

--Average, Minimum, and Maximum Sales per Transaction
SELECT 
    AVG(total_sale) AS avg_sale, 
    MIN(total_sale) AS min_sale, 
    MAX(total_sale) AS max_sale
FROM retail_sales;
```
## Sales Performance Analysis
```sql
--Total Sales and Quantity Sold by Category
SELECT 
    category, 
    SUM(quantity) AS total_quantity, 
    SUM(total_sale) AS total_sales
FROM retail_sales
GROUP BY category;

--Total Sales by Date
SELECT 
    sale_date, 
    SUM(total_sale) AS total_sales
FROM retail_sales
GROUP BY sale_date
ORDER BY sale_date;

--Monthly Sales Trend
SELECT 
    YEAR(sale_date) AS year, 
    MONTH(sale_date) AS month, 
    SUM(total_sale) AS total_sales
FROM retail_sales
GROUP BY YEAR(sale_date), MONTH(sale_date)
ORDER BY year, month;

--Peak Sale Hours
SELECT 
    DATEPART(HOUR, sale_time) AS hour, 
    SUM(total_sale) AS total_sales
FROM retail_sales
GROUP BY DATEPART(HOUR, sale_time)
ORDER BY hour;
```
## Customer Behavior Analysis
```sql
--Top 10 Customers by Total Sales
SELECT TOP 10
    customer_id, 
    SUM(total_sale) AS total_sales
FROM retail_sales
GROUP BY customer_id
ORDER BY total_sales DESC;

--Number of Transactions per Customer
SELECT 
    customer_id, 
    COUNT(transactions_id) AS transaction_count
FROM retail_sales
GROUP BY customer_id
ORDER BY transaction_count DESC;
```
## Profitability Analysis
```sql
--Profit by Category
SELECT 
    category, 
    SUM(total_sale - cogs) AS total_profit
FROM retail_sales
GROUP BY category
ORDER BY total_profit DESC;

--Total Profit Generated by Each Customer
SELECT 
    customer_id, 
    SUM(total_sale - cogs) AS total_profit
FROM retail_sales
GROUP BY customer_id
ORDER BY total_profit DESC;
```
## Inventory and Product Analysis
```sql
--Most Frequent Sold Categories
SELECT 
    category, 
    SUM(quantity) AS total_quantity
FROM retail_sales
GROUP BY category
ORDER BY total_quantity DESC;

--Average Price per Unit by Category
SELECT 
    category, 
    AVG(price_per_unit) AS avg_price
FROM retail_sales
GROUP BY category;
```
## Anomaly Detection
```sql
--Identify Transactions with Unusually High or Low Total Sales
SELECT *
FROM retail_sales
WHERE total_sale > (SELECT AVG(total_sale) + 3 * STDEV(total_sale) FROM retail_sales)
OR total_sale < (SELECT AVG(total_sale) - 3 * STDEV(total_sale) FROM retail_sales);

--Check for Transactions Where COGS is Higher Than Total Sales
SELECT *
FROM retail_sales
WHERE cogs > total_sale;
```
## Sales Trend Analysis
Analyze Sales Trends Over Time Using SQL Window Functions
```sql
SELECT 
    sale_date, 
    SUM(total_sale) AS daily_sales,
    AVG(SUM(total_sale)) OVER (ORDER BY sale_date ROWS BETWEEN 6 PRECEDING AND CURRENT ROW) AS rolling_avg_7_days
FROM retail_sales
GROUP BY sale_date
ORDER BY sale_date;
```
## Customer Segmentation
Categorize Customers Based on Total Sales
```sql
SELECT 
    customer_id, 
    SUM(total_sale) AS total_sales,
    CASE 
        WHEN SUM(total_sale) > 5000 THEN 'High-Value'
        WHEN SUM(total_sale) BETWEEN 1000 AND 5000 THEN 'Medium-Value'
        ELSE 'Low-Value'
    END AS customer_segment
FROM retail_sales
GROUP BY customer_id;
```
