## Data Cleaning

### Checking for NULL Values
The first step in data cleaning is identifying any NULL values in the dataset. This query checks for missing values in the key columns:

```sql
SELECT * FROM retail_sales
WHERE 
    sale_date IS NULL OR sale_time IS NULL OR customer_id IS NULL OR 
    gender IS NULL OR age IS NULL OR category IS NULL OR 
    quantity IS NULL OR price_per_unit IS NULL OR cogs IS NULL;

### Deleting NULL Values
Once NULL values are identified, the following query deletes records with any NULL values in the essential columns:

```sql
DELETE FROM retail_sales
WHERE 
    sale_date IS NULL OR sale_time IS NULL OR customer_id IS NULL OR 
    gender IS NULL OR age IS NULL OR category IS NULL OR 
    quantity IS NULL OR price_per_unit IS NULL OR cogs IS NULL;
## Data Exploration
Total Number of Sales
To get an overview of the total number of sales:

sql
Copy code
SELECT COUNT(*) FROM retail_sales;
Number of Unique Customers
To understand customer diversity:

sql
Copy code
SELECT COUNT(DISTINCT customer_id) FROM retail_sales;
Types of Categories
This query reveals all unique categories in the dataset:

sql
Copy code
SELECT DISTINCT category FROM retail_sales;
Total Sale Value
To calculate the total sales value across all transactions:

sql
Copy code
SELECT SUM(total_sale) AS total_sales FROM retail_sales;
Average, Minimum, and Maximum Sales per Transaction
To understand the range of sales per transaction:

sql
Copy code
SELECT 
    AVG(total_sale) AS avg_sale, 
    MIN(total_sale) AS min_sale, 
    MAX(total_sale) AS max_sale
FROM retail_sales;
Customer Demography
Distribution of Customers by Gender
sql
Copy code
SELECT gender, COUNT(DISTINCT customer_id) AS customer_count FROM retail_sales GROUP BY gender;
Age Group Distribution
sql
Copy code
SELECT 
    CASE 
        WHEN age < 18 THEN 'Under 18'
        WHEN age BETWEEN 18 AND 25 THEN '18-25'
        WHEN age BETWEEN 26 AND 40 THEN '26-40'
        WHEN age BETWEEN 41 AND 60 THEN '41-60'
        ELSE 'Above 60'
    END AS age_group, 
    COUNT(customer_id) AS customer_count
FROM retail_sales
GROUP BY 
    CASE 
        WHEN age < 18 THEN 'Under 18'
        WHEN age BETWEEN 18 AND 25 THEN '18-25'
        WHEN age BETWEEN 26 AND 40 THEN '26-40'
        WHEN age BETWEEN 41 AND 60 THEN '41-60'
        ELSE 'Above 60'
    END;
Sales Performance Analysis
Total Sales and Quantity Sold by Category
sql
Copy code
SELECT 
    category, 
    SUM(quantity) AS total_quantity, 
    SUM(total_sale) AS total_sales
FROM retail_sales
GROUP BY category;
Total Sales by Date
sql
Copy code
SELECT 
    sale_date, 
    SUM(total_sale) AS total_sales
FROM retail_sales
GROUP BY sale_date
ORDER BY sale_date;
Monthly Sales Trend
sql
Copy code
SELECT 
    YEAR(sale_date) AS year, 
    MONTH(sale_date) AS month, 
    SUM(total_sale) AS total_sales
FROM retail_sales
GROUP BY YEAR(sale_date), MONTH(sale_date)
ORDER BY year, month;
Peak Sale Hours
sql
Copy code
SELECT 
    DATEPART(HOUR, sale_time) AS hour, 
    SUM(total_sale) AS total_sales
FROM retail_sales
GROUP BY DATEPART(HOUR, sale_time)
ORDER BY hour;

Anomaly Detection
Identify Transactions with Unusually High or Low Total Sales
sql
Copy code
SELECT *
FROM retail_sales
WHERE total_sale > (SELECT AVG(total_sale) + 3 * STDEV(total_sale) FROM retail_sales)
OR total_sale < (SELECT AVG(total_sale) - 3 * STDEV(total_sale) FROM retail_sales);
Check for Transactions Where COGS is Higher Than Total Sales
sql
Copy code
SELECT *
FROM retail_sales
WHERE cogs > total_sale;
Sales Trend Analysis
Analyze Sales Trends Over Time Using SQL Window Functions
sql
Copy code
SELECT 
    sale_date, 
    SUM(total_sale) AS daily_sales,
    AVG(SUM(total_sale)) OVER (ORDER BY sale_date ROWS BETWEEN 6 PRECEDING AND CURRENT ROW) AS rolling_avg_7_days
FROM retail_sales
GROUP BY sale_date
ORDER BY sale_date;
Customer Segmentation
Categorize Customers Based on Total Sales

SELECT 
    customer_id, 
    SUM(total_sale) AS total_sales,
    CASE 
        WHEN SUM(total_sale) > 5000 THEN 'High-Value'
        WHEN SUM(total_sale) BETWEEN 1000 AND 5000 THEN 'Medium-Value'
        ELSE 'Low-Value'
    END AS customer_segment
FROM retail_sales
GROUP BY customer_id;
