# Retail Sales SQL Project
# Project Overview

This project focuses on cleaning and analyzing a retail sales dataset using SQL. The key objectives include handling missing values, exploring the data, analyzing customer behavior, and assessing sales performance and profitability.

#Data Cleaning

1. Checking NULL Values

To identify incomplete records:

SELECT * FROM retail_sales
WHERE 
    sale_date IS NULL OR sale_time IS NULL OR customer_id IS NULL OR 
    gender IS NULL OR age IS NULL OR category IS NULL OR 
    quantity IS NULL OR price_per_unit IS NULL OR cogs IS NULL;

2. Deleting NULL Values

To remove records with missing values:

DELETE FROM retail_sales
WHERE 
    sale_date IS NULL OR sale_time IS NULL OR customer_id IS NULL OR 
    gender IS NULL OR age IS NULL OR category IS NULL OR 
    quantity IS NULL OR price_per_unit IS NULL OR cogs IS NULL;

Data Exploration

Key Metrics

Total Number of Sales:

SELECT COUNT(*) FROM retail_sales;

Number of Unique Customers:

SELECT COUNT(DISTINCT customer_id) FROM retail_sales;

Distinct Product Categories:

SELECT DISTINCT category FROM retail_sales;

Total Sale Value:

SELECT SUM(total_sale) AS total_sales FROM retail_sales;

Average, Minimum, and Maximum Sales Per Transaction:

SELECT 
    AVG(total_sale) AS avg_sale, 
    MIN(total_sale) AS min_sale, 
    MAX(total_sale) AS max_sale
FROM retail_sales;

Customer Demographics

Distribution by Gender:

SELECT gender, COUNT(DISTINCT customer_id) AS customer_count FROM retail_sales GROUP BY gender;

Age Group Distribution:

SELECT 
    CASE 
        WHEN age < 18 THEN 'Under 18'
        WHEN age BETWEEN 18 AND 25 THEN '18-25'
        WHEN age BETWEEN 26 AND 40 THEN '26-40'
        WHEN age BETWEEN 41 AND 60 THEN '41-60'
        ELSE 'Above 60'
    END AS age_group, 
    COUNT(customer_id) AS customer_count
FROM retail_sales
GROUP BY 
    CASE 
        WHEN age < 18 THEN 'Under 18'
        WHEN age BETWEEN 18 AND 25 THEN '18-25'
        WHEN age BETWEEN 26 AND 40 THEN '26-40'
        WHEN age BETWEEN 41 AND 60 THEN '41-60'
        ELSE 'Above 60'
    END;

Sales Performance Analysis

Category-Wise Sales

Total sales and quantities sold by category:

SELECT 
    category, 
    SUM(quantity) AS total_quantity, 
    SUM(total_sale) AS total_sales
FROM retail_sales
GROUP BY category;

Temporal Trends

Daily Sales:

SELECT 
    sale_date, 
    SUM(total_sale) AS total_sales
FROM retail_sales
GROUP BY sale_date
ORDER BY sale_date;

Monthly Sales Trends:

SELECT 
    YEAR(sale_date) AS year, 
    MONTH(sale_date) AS month, 
    SUM(total_sale) AS total_sales
FROM retail_sales
GROUP BY YEAR(sale_date), MONTH(sale_date)
ORDER BY year, month;

Peak Sale Hours:

SELECT 
    DATEPART(HOUR, sale_time) AS hour, 
    SUM(total_sale) AS total_sales
FROM retail_sales
GROUP BY DATEPART(HOUR, sale_time)
ORDER BY hour;

Customer Behavior Analysis

Top Customers

Top 10 customers by total sales:

SELECT TOP 10
    customer_id, 
    SUM(total_sale) AS total_sales
FROM retail_sales
GROUP BY customer_id
ORDER BY total_sales DESC;

Transaction Frequency Per Customer:

SELECT 
    customer_id, 
    COUNT(transactions_id) AS transaction_count
FROM retail_sales
GROUP BY customer_id
ORDER BY transaction_count DESC;

Profitability Analysis

Profit by Category

Profit calculation:

SELECT 
    category, 
    SUM(total_sale - cogs) AS total_profit
FROM retail_sales
GROUP BY category
ORDER BY total_profit DESC;

Customer Profitability

Total profit generated by each customer:

SELECT 
    customer_id, 
    SUM(total_sale - cogs) AS total_profit
FROM retail_sales
GROUP BY customer_id
ORDER BY total_profit DESC;

Inventory and Product Analysis

Top-Selling Categories

Most frequently sold categories:

SELECT 
    category, 
    SUM(quantity) AS total_quantity
FROM retail_sales
GROUP BY category
ORDER BY total_quantity DESC;

Category-Wise Pricing

Average price per unit by category:

SELECT 
    category, 
    AVG(price_per_unit) AS avg_price
FROM retail_sales
GROUP BY category;

Anomaly Detection

Unusual Sales

Identify transactions with unusually high or low total sales:

SELECT *
FROM retail_sales
WHERE total_sale > (SELECT AVG(total_sale) + 3 * STDEV(total_sale) FROM retail_sales)
   OR total_sale < (SELECT AVG(total_sale) - 3 * STDEV(total_sale) FROM retail_sales);

Loss Transactions

Check for transactions where COGS exceeds total sales:

SELECT *
FROM retail_sales
WHERE cogs > total_sale;

Advanced Analysis

Rolling Averages

Sales trends over time:

SELECT 
    sale_date, 
    SUM(total_sale) AS daily_sales,
    AVG(SUM(total_sale)) OVER (ORDER BY sale_date ROWS BETWEEN 6 PRECEDING AND CURRENT ROW) AS rolling_avg_7_days
FROM retail_sales
GROUP BY sale_date
ORDER BY sale_date;

Customer Segmentation

High-value, medium-value, and low-value customers:

SELECT 
    customer_id, 
    SUM(total_sale) AS total_sales,
    CASE 
        WHEN SUM(total_sale) > 5000 THEN 'High-Value'
        WHEN SUM(total_sale) BETWEEN 1000 AND 5000 THEN 'Medium-Value'
        ELSE 'Low-Value'
    END AS customer_segment
FROM retail_sales
GROUP BY customer_id;
